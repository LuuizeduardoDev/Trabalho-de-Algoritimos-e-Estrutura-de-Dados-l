## Ordenação de Notas de uma Turma Pequena

O projeto permite ordenar as notas do alunos por meio do algoritimo : "Bobble Short".

## Tecnologias Utilizadas

* **JAVA** (versão: 17.0.20)

## Sobre o Projeto

o projeto conta com um exemplo prático de uso de vetores ('arrays') em Java para armazenar e manipular as **notas** dos alunos diretamente
no código.
